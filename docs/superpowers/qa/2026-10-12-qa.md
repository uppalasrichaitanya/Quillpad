## Not covered by automation

- **PDF export** opens the system print dialog; it renders the same HTML as the styled-HTML export, which is covered.
- **Choosing a notes folder** uses the native folder picker; the underlying `set_notes_dir` is unchanged from 0.1.
- **Importing a real chapter with a valid key** spends API credit — run once by the author before publishing.

## Bugs found and fixed by this loop

- `setDiagramTheme` was never imported in `main.js` (shipped in 0.1.0): theme switching aborted before saving, and styled-HTML / PDF / cheat-sheet exports threw. Fixed in 19fdb6a with a guard test (`tests/imports.test.mjs`).
- Import asked for a key only after the wizard was filled in; it now asks at the "+ import chapter file" button.
