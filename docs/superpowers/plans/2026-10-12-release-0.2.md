# Quillpad 0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Quillpad exe that a brand-new user with no `.env` can set up and use (bring-your-own-key), plus a premium "Desk at night" landing page.

**Architecture:**
- **Backend:** AI configuration moves into a pure, unit-tested Rust module (`ai_config.rs`: defaults, URL normalization, legacy migration, error mapping). A small `keystore.rs` wraps Windows Credential Manager.
- **Frontend:** a first-run welcome flow (`src/onboarding.js`) and a key gate (`src/ai-gate.js`) sit in front of every AI action.
- **Website:** a from-scratch React/Tailwind rewrite in `web/src` that links downloads to GitHub Releases.

**Tech Stack:**
- Tauri 2, Rust (reqwest, serde, `keyring` 3);
- vanilla JS frontend + Vite;
- website: React 19, Vite 7, Tailwind v4, Motion 13, puppeteer-core (Edge) for verification.

**Spec:** `docs/superpowers/specs/2026-10-12-release-0.2-design.md`

## Global Constraints

- **Default API:** base URL `https://api.anthropic.com`, default model `claude-opus-5-5`, header `anthropic-version: 2023-06-01`.
- **Request shape:** no `temperature`, no `thinking` param, no assistant prefill in any Anthropic request.
- **Output budget:** `max_tokens` 16000 on non-streaming Messages calls.
- **First-party extras:** `output_config.effort: "medium"` and `fallbacks: "default"` + `anthropic-beta: server-side-fallback-2026-07-01` are sent **only** when the base URL host is `api.anthropic.com`.
- **Key storage:** the API key is never written to `settings.json`. Credential Manager service `com.quillpad.app`, user `llm_api_key`.
- **UI copy:** must not mention `.env`, seekai, gorouter or inception.
- **Version:** `0.2.0` in `package.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json`.
- **Rust toolchain:** not on PATH in Bash. Prefix commands with `export PATH="$HOME/.cargo/bin:$PATH" &&`.
- **Release build:** `npm run tauri build -- --no-bundle` from the repo root (never bare `cargo build --release` — that skips embedded assets).
- **Approval gates:** no `git push`, no GitHub release, no deploy without asking the author first.
- **Website palette:**
  - desk `#14110D`; desk text `#EDE3D0`; desk soft text `#A89B87`;
  - paper `#F3EADA` / `#E8D8BB`; ink `#362B1E`; ink-soft `#6C5D49`;
  - rust `#BC5A32` is the only accent.
- **Website type:** Fraunces, Source Serif 4, IBM Plex Mono, Caveat (≤ 2 uses).

## Review Focus

1. **Existing user's `settings.json` with a plaintext key or the old OpenAI defaults.** Expect the key to move to Credential Manager, the defaults to migrate, and nothing to be lost. Test in Task 1 + Task 2.
2. **Pasted key with surrounding whitespace / newline, or a base URL pasted as `https://api.anthropic.com/v1/` or `.../v1/messages`.** Expect it to normalise to a working URL. Test in Task 1.
3. **User hits an AI action with no key while offline-capable features stay usable.** Expect a clear "add a key" prompt, not a raw Rust error, and the online ask mode to fall back to offline. Test in Task 4 (manual QA checklist) + Task 3 (`no_key_message`).
4. **Credential Manager unavailable (keyring error).** Expect the app to still boot and offline features to work, with settings showing the error message rather than crashing. Covered in Task 2 (errors are returned as `Err(String)`, never `unwrap`).
5. **Model reply cut off by `max_tokens` or declined (`refusal`).** Expect a plain-English error instead of "bad json". Test in Task 3.

```rust
pub fn normalize_base_url(raw: &str) -> String {
    let mut s = raw.trim().trim_end_matches('/').to_string();
    for suffix in ["/messages", "/v1"] {
        if s.ends_with(suffix) {
            s.truncate(s.len() - suffix.len());
            s = s.trim_end_matches('/').to_string();
        }
    }
    if s.is_empty() { DEFAULT_BASE_URL.to_string() } else { s }
}

pub fn effective_model(raw: &str) -> String {
    let m = raw.trim();
    if m.is_empty() { DEFAULT_MODEL.to_string() } else { m.to_string() }
}

pub fn messages_url(base: &str) -> String {
    format!("{}/v1/messages", normalize_base_url(base))
}

pub fn models_url(base: &str) -> String {
    format!("{}/v1/models", normalize_base_url(base))
}

pub fn is_first_party(base: &str) -> bool {
    let b = normalize_base_url(base);
    let host = b.split("://").nth(1).unwrap_or(&b).split('/').next().unwrap_or("");
    host == "api.anthropic.com"
}

/// 0.1 shipped OpenAI-shaped defaults that never worked with the Messages API.
pub fn migrate_legacy(s: &mut Settings) -> bool {
    let legacy_url = s.llm_base_url.trim().trim_end_matches('/') == "https://api.openai.com/v1";
    let legacy_model = s.llm_model.trim() == "gpt-4o-mini";
    if legacy_url && legacy_model {
        s.llm_base_url = DEFAULT_BASE_URL.to_string();
        s.llm_model = DEFAULT_MODEL.to_string();
        return true;
    }
    false
}

pub fn describe_status(status: u16, body: &str) -> String {
    match status {
        401 | 403 => "that key was rejected — check it was copied in full".to_string(),
        404 => "nothing answered at that address — check the base URL in settings".to_string(),
        429 => "the AI service is rate limiting you — wait a minute and try again".to_string(),
        500..=599 => "the AI service is busy right now — try again shortly".to_string(),
        _ => {
            let detail = serde_json::from_str::<serde_json::Value>(body)
                .ok()
                .and_then(|v| v.pointer("/error/message").and_then(|m| m.as_str()).map(str::to_string))
                .unwrap_or_else(|| body.lines().next().unwrap_or("").chars().take(160).collect());
            format!("the AI service returned {status}: {detail}")
        }
    }
}

pub fn no_key_message() -> &'static str {
    "add an API key in settings to use AI features — reading, search, flashcards and exams work without one"
}
```

```rust
//! The API key lives in the OS credential store (Windows Credential Manager),
//! never in settings.json.

const SERVICE: &str = "com.quillpad.app";
const USER: &str = "llm_api_key";

fn entry() -> Result<keyring::Entry, String> {
    keyring::Entry::new(SERVICE, USER).map_err(|e| format!("credential store unavailable: {e}"))
}

pub fn get() -> Result<Option<String>, String> {
    match entry()?.get_password() {
        Ok(k) if !k.trim().is_empty() => Ok(Some(k)),
        Ok(_) | Err(keyring::Error::NoEntry) => Ok(None),
        Err(e) => Err(format!("could not read the saved key: {e}")),
    }
}

pub fn set(key: &str) -> Result<(), String> {
    entry()?
        .set_password(key.trim())
        .map_err(|e| format!("could not save the key: {e}"))
}

pub fn clear() -> Result<(), String> {
    match entry()?.delete_credential() {
        Ok(()) | Err(keyring::Error::NoEntry) => Ok(()),
        Err(e) => Err(format!("could not remove the key: {e}")),
    }
}

/// Pull a 0.1-era plaintext key out of loaded settings (caller stores it).
pub fn take_plaintext(s: &mut crate::library::Settings) -> Option<String> {
    let k = std::mem::take(&mut s.llm_api_key);
    let k = k.trim().to_string();
    if k.is_empty() { None } else { Some(k) }
}
```

```rust
/// Load settings, migrate 0.1 leftovers (plaintext key, OpenAI defaults) and
/// fill the runtime-only key from the credential store.
pub fn settings_with_key(app: &AppHandle) -> Result<Settings, String> {
    let data = app_data(app);
    let mut settings = Settings::load(&data)?;
    let mut dirty = crate::ai_config::migrate_legacy(&mut settings);
    if let Some(plain) = crate::keystore::take_plaintext(&mut settings) {
        crate::keystore::set(&plain)?;
        dirty = true;
    }
    if dirty {
        settings.save(&data)?;
    }
    settings.llm_api_key = crate::keystore::get()?.unwrap_or_default();
    Ok(settings)
}

        Err(e) => (crate::distill::has_env_endpoint(), Some(e)),

        base_url: crate::ai_config::normalize_base_url(&plain.llm_base_url),
        model: crate::ai_config::effective_model(&plain.llm_model),
        onboarded: plain.onboarded,
        key_error,
    })
}

#[tauri::command]
pub fn set_llm_settings(
    app: AppHandle,
    base_url: String,
    model: String,
    api_key: Option<String>,
    clear_key: bool,
) -> Result<(), String> {
    let data = app_data(&app);
    let mut settings = Settings::load(&data)?;
    settings.llm_base_url = crate::ai_config::normalize_base_url(&base_url);
    settings.llm_model = crate::ai_config::effective_model(&model);
    settings.llm_api_key.clear();
    if clear_key {
        crate::keystore::clear()?;
    } else if let Some(k) = api_key.filter(|k| !k.trim().is_empty()) {
        crate::keystore::set(&k)?;
    }
    settings.save(&data)
}

#[tauri::command]
pub fn complete_onboarding(app: AppHandle) -> Result<(), String> {
    let data = app_data(&app);
    let mut settings = Settings::load(&data)?;
    settings.onboarded = true;
    settings.save(&data)
}
```

```rust
/// Check a key without spending tokens: GET /v1/models. Some compatible
/// gateways lack that route, so a 404 falls back to a 1-token message.
#[tauri::command]
pub async fn test_connection(
    app: AppHandle,
    base_url: String,
    model: String,
    api_key: Option<String>,
) -> Result<String, String> {
    let key = match api_key.filter(|k| !k.trim().is_empty()) {
        Some(k) => k.trim().to_string(),
        None => settings_with_key(&app)?.llm_api_key,
    };
    if key.is_empty() {
        return Err("paste a key first".into());
    }
    let client = reqwest::Client::builder()
        .timeout(std::time::Duration::from_secs(20))
        .build()
        .map_err(error)?;
    let send = |req: reqwest::RequestBuilder| async move {
        req.header("x-api-key", &key)
            .header("anthropic-version", "2023-06-01")
            .send()
            .await
            .map_err(|e| if e.is_connect() || e.is_timeout() {
                "couldn't reach the AI service — check your internet connection".to_string()
            } else {
                format!("request failed: {e}")
            })
    };
    let resp = send(client.get(crate::ai_config::models_url(&base_url))).await?;
    let status = resp.status().as_u16();
    if (200..300).contains(&status) {
        return Ok("connected".into());
    }
    if status != 404 {
        let body = resp.text().await.unwrap_or_default();
        return Err(crate::ai_config::describe_status(status, &body));
    }
    let body = serde_json::json!({
        "model": crate::ai_config::effective_model(&model),
        "max_tokens": 1,
        "messages": [{"role": "user", "content": "ping"}],
    });
    let resp = send(client.post(crate::ai_config::messages_url(&base_url)).json(&body)).await?;
    let status = resp.status().as_u16();
    if (200..300).contains(&status) {
        Ok("connected".into())
    } else {
        Err(crate::ai_config::describe_status(status, &resp.text().await.unwrap_or_default()))
    }
}
```

```js
const bytes = readFileSync(exe);
const v = pkg.version;
const info = {

  url: `https://github.com/uppalasrichaitanya/Quillpad/releases/download/v${v}/Quillpad.exe`,
  sizeBytes: statSync(exe).size,
  sha256: createHash('sha256').update(bytes).digest('hex'),

writeFileSync(out, `// generated by scripts/release-info.mjs — do not edit\nexport const RELEASE = ${JSON.stringify(info, null, 2)} as const;\n`);
```
