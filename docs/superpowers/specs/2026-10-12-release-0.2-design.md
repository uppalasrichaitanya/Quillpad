# Quillpad 0.2 — release for friends + "Desk at night" website

Date: 2026-10-12 · Branch: `release-0.2`

## Intent

Make Quillpad something the author can hand to friends and strangers:

- a Windows exe that works for a brand-new user with **no `.env` and no help**;
- a premium landing page they would be proud to link to.

Decisions taken with the author:

- AI access is **bring-your-own-key** (no embedded key, no proxy server).
- Website direction is **"Desk at night"** (dark desk, lit cream paper).
- Order: app (B) first, then website (A).
- Nothing is pushed or published without asking first.

## B. App — release-ready

### B1. First-run setup + BYOK

- **Fresh install:** a fresh install (no `settings.json`) shows a welcome screen in the app's own style:
  1. notes folder (default shown, "choose…" available);
  2. AI key: paste key → **Test connection** → success / plain-English failure; or **skip — use offline**.
- **Defaults:** base URL `https://api.anthropic.com`, model `claude-opus-5-5`. Users who only paste a key need nothing else.
- **Advanced fields:** base URL and model stay editable under an "advanced" disclosure in settings.
- **New `test_connection` command:** checks the key without spending tokens via `GET {base}/v1/models` (headers `x-api-key`, `anthropic-version: 2023-06-01`).
  - If that 404s (some compatible gateways lack it), fall back to a 1-token Messages request.
  - Errors are mapped to: invalid key (401/403), no network, endpoint not found (404), rate limited (429), and other (status + first line).
- **No key configured:** AI actions (import distill, online ask, quiz/written generation, exam grading) show an inline "add a key in settings to use this" with a button that opens settings, instead of a raw error.
- **Settings copy:** settings no longer mention `.env` / seekai / gorouter.

### B2. Bug fixes found in audit

- **Wrong defaults:** settings defaulted to `https://api.openai.com/v1` + `gpt-4o-mini`, but the custom endpoint always speaks Anthropic Messages at `/v1/messages`. New defaults are as in B1. Existing settings files that still hold the old OpenAI defaults are migrated.
- **Empty base URL:** an empty base URL produced the URL `/v1/messages`. An empty value now falls back to the default.
- **Empty model:** an empty model falls back to the default.
- **Output budget:** `max_tokens` is 8000. On Claude Opus 5.5 thinking is always on and counts toward that budget, so long chapters can truncate the note JSON.
  - Raise it to 16000 (non-streaming).
  - Set `output_config.effort: "medium"` explicitly, only for `api.anthropic.com` endpoints.
- **Stop reasons:** handle `stop_reason` explicitly.
  - `max_tokens` → "chapter too long for one pass" message.
  - `refusal` → plain message.
- **Refusal fallbacks:** for `api.anthropic.com` only, send the server-side refusal fallback (`fallbacks: "default"` + beta `server-side-fallback-2026-07-01`).
- **`.env` chain:** the `.env` endpoints (seekai, gorouter, inception) remain as a developer fallback. They are only consulted when a `.env` is actually found, and are never mentioned in UI copy.

### B3. Hardening

- **CSP:** replace `"csp": null` with a restrictive policy:
  - `default-src 'self'`;
  - images allow `data:`, `blob:`, `asset:`, `http://asset.localhost`;
  - fonts `'self' data:`;
  - `connect-src` limited to IPC + asset;
  - workers `'self' blob:` (pdf.js);
  - inline styles allowed (diagram SVG relies on them).

  Network calls happen in Rust, not the webview.
- **Asset protocol:** narrow scope `"**"` to PDFs only (`**/*.pdf`), which is all the webview reads through it (scanned-PDF rendering).
- **API key storage:** store the key in Windows Credential Manager via the `keyring` crate. `settings.json` keeps a flag only. A plaintext key found in an existing `settings.json` is migrated into the keyring and removed from the file.

### B4. Tests + verification loop

- Rust unit tests:
  - note parse/render round-trip;
  - slug;
  - `.env` parsing;
  - endpoint resolution (defaults, empty URL, migration, `.env` precedence);
  - error mapping for `test_connection`.
- Bring the existing JS test scripts (`scripts/test_*.mjs`) into git, fix any that fail, and add `npm test` that runs them.
- Verification loop, repeated until clean:
  1. Build the release exe (`npm run tauri build -- --no-bundle`).
  2. Move the real app-data folder aside (`%APPDATA%\com.quillpad.app` → `.qa-backup`), copy the exe to a folder with no `.env` ancestor, and launch as a fresh user.
  3. Drive every flow: first run (skip and key paths), open seed notes, offline ask, online ask without a key, flashcards, quiz, practice writing, mock exam, edit note, export md/html/pdf, cheat sheet, theme toggle, settings save, change notes folder, re-launch persistence.
  4. Fix failures and repeat.
  5. Restore the real app-data folder at the end of every session, including on failure.

### B5. Release polish

- Version `0.2.0` in `package.json`, `Cargo.toml`, `tauri.conf.json`.
- README: "Getting your API key in 2 minutes", and remove the seekai/gorouter defaults from the user-facing docs.
- `src-tauri/src/exports.rs` is untracked dead code: delete it locally after confirming no `mod exports` references it, and drop its `.gitignore` line.
- GitHub Release v0.2.0 with exe + SHA-256, **after the author confirms**.

## A. Website — "Desk at night"

### Visual system

- **Desk:** `#14110D` (warm near-black) with a soft top-left light falloff and subtle film grain.
- **Paper:** `#F3EADA` / `#E8D8BB`. Ink `#362B1E`. One accent: rust `#BC5A32`. Cream text on the desk `#EDE3D0`, soft `#A89B87`.
- **Type:**
  - Fraunces for display (600, italic for emphasis);
  - Source Serif 4 for body;
  - IBM Plex Mono for meta labels;
  - Caveat in at most two places.
- **Paper objects:** layered shadows (contact + ambient), slight rotation, tape only on the hero sheet.
- **Motion:** purposeful, ≤ 600ms per transition except the hero sequence (~3s, plays once, replay button). `prefers-reduced-motion` shows the finished state.

### Sections

1. **Nav:** wordmark, three links, Download button.
2. **Hero:**
   - Headline + one-line value prop + Download button (version · size);
   - right side: the dense textbook page → rust ink sweep → folds into a Quillpad note → cell diagram draws itself.
3. **Watch it work:** three steps (PDF → note → study), each showing an HTML recreation of the real app UI on paper. Auto-advances, and can be stepped manually.
4. **Features grid:** six tiles, three of them live:
   - offline ask: working search over the seed notes;
   - flashcard: flips;
   - mock exam: ticking clock;
   - hand-drawn diagrams;
   - Midnight Ink toggle;
   - export.
5. **Your notes are files:** folder tree + raw `.md` side by side; "No account. No cloud. Your API key, your machine."
6. **Download + FAQ:** download card (version, size, SHA-256 with copy, SmartScreen note). FAQ covers:
   - free?
   - API key (link to the README guide)
   - Mac?
   - offline?
   - where are my notes?
7. **Footer.**

Target height ≈ 4,500px at 1440 wide. No third-party AI provider names on the page.

### Technical

- Rewrite `web/src` from scratch. Stack stays React 19 + Vite + Tailwind v4 + Motion.
- **Download:** links to the GitHub Release asset. A build-time script reads version/size/SHA-256 from the release build output, so the page cannot drift. The exe is no longer copied into the site.
- **Hosting:** static `dist/`, deployable to GitHub Pages / Netlify / Vercel.
- **Verification** (rewritten `scripts/verify-page.mjs`, headless Edge):
  - no horizontal overflow at 390 and 1440;
  - zero console errors;
  - reduced-motion render;
  - text contrast ≥ 4.5:1;
  - interactive demos work;
  - Lighthouse performance and accessibility ≥ 95.
- Un-ignore `web/` (keep `web/node_modules`, `web/dist*` ignored) and commit it.

## Out of scope

macOS/Linux builds, code signing, auto-update, a hosted proxy, accounts.
